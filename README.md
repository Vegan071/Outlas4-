# Point of No Return: Eclipse 3D

Браузерный хоррор от первого лица. Проект находится в процессе поэтапной миграции с Three.js на Babylon.js.

## Текущий статус миграции

Ветка `feat/babylon-migration` содержит первый каркас Babylon.js:

- отдельную точку входа `src/babylon/main.ts`;
- создание WebGL-движка и сцены;
- камеру от первого лица с WASD, мышью, гравитацией и базовыми столкновениями;
- тестовую ночную лесную сцену с туманом, освещением и Thin Instances;
- тестовую записку для проверки взаимодействия;
- заготовки `AudioManager` и `AssetLoader` для будущих звуков и GLB-моделей.

Старый Three.js-код сохранён и пока не удаляется: он служит источником для переноса механик. Текущая браузерная точка входа уже переключена на Babylon.js. Это фундамент миграции, а не завершённый перенос старой игры: ИИ Вендиго, гаджеты, полноценные квесты, сохранения и старые локации ещё предстоит переносить.

## Запуск

```bash
npm install
npm run dev
npm run build
npm run typecheck
```

Нужен Node.js 18+ для используемой ветки Vite 5.

## Управление в Babylon-прототипе

| Клавиша | Действие |
|---|---|
| `W A S D` | движение |
| Мышь | обзор |
| `Shift` | ускорение |
| `E` | подобрать тестовую записку |
| `Esc` | пауза / выход из Pointer Lock |

## Структура миграционного каркаса

```text
src/babylon/
├── main.ts                  новая точка входа
├── engine/createEngine.ts   WebGL engine и Scene
├── player/createPlayer.ts   камера и базовое управление
├── world/createWorld.ts     тестовая лесная сцена
├── audio/AudioManager.ts    единая точка управления звуком
└── assets/AssetLoader.ts    загрузка GLB/glTF
```

## Следующие этапы

1. Перенести оригинальную геометрию леса, города, POI и освещение.
2. Перенести игрока, гаджеты, записки и взаимодействия.
3. Перенести ИИ Вендиго; на первом проходе сохранить Yuka, чтобы не менять ИИ и рендерер одновременно.
4. Подключить лицензированные звуковые ассеты и GLB-модели.
5. Добавить системы здоровья, выносливости, инвентаря, квестов и сохранений.

## Старый Three.js-код

`src/main.js`, `src/core/`, `src/world/`, `src/game/` и `src/entities/` пока сохранены. Они не подключены к новой точке входа, но нужны как референс для последовательного переноса.
