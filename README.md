# Point of No Return: Eclipse 3D

Браузерный survival horror от первого лица. Ветка `feat/babylon-migration` переносит игру с Three.js на Babylon.js. Основная ветка `main` не изменяется.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run typecheck
npm run build
npm run dev
```

Используйте `npm install`, а не `npm ci`: lock-файл ещё нужно синхронизировать после миграции зависимостей.

## Перенесено в Babylon.js

- **Мир:** процедурный рельеф 800×800, 800 инстансированных сосен, дорога, 14 зданий, 6 брошенных автомобилей, 14 уличных фонарей, домик лесника, радиовышка и подстанция.
- **Процедурные текстуры:** асфальт, земля, кора, фасады, граффити, бумага записок, кожа и кость Вендиго.
- **Игрок:** first-person камера, коллизии, ходьба/бег/прыжок, фонарик, фотовспышка, выносливость, шум шагов и хруста веток.
- **Руки и гаджеты:** процедурные руки от первого лица, модель фонарика и работающий экран ЭМП с зелёными уликами, красным Вендиго и синей машиной.
- **Вендиго:** процедурная модель с позвоночником, рёбрами, рогами, клыками и анимацией конечностей; FSM патруля, обнаружения зрением/светом/шумом, расследования, засады, погони и оглушения.
- **Другие встречи:** фантом и отдельная последовательность jumpscare.
- **Цикл мира:** закат/ночь, кровавая луна, падающий пепел, туман и уличные фонари.
- **Эвакуация:** 10 записок, сохранение прогресса, случайное появление полицейской машины, мигающая световая балка и процедурная сирена.
- **Звук:** CC0-эффекты SFXMint — лесная атмосфера, дрон, шаги по асфальту/гравию, хруст веток, рычание, сердцебиение, затвор, скример и ветер. Ссылки и лицензии перечислены в [SOUND_ASSETS.md](./SOUND_ASSETS.md).
- **Настройки:** чувствительность мыши, громкость, bloom и режим низкой графики.
- **Проверки:** GitHub Actions запускает TypeScript check и production build на каждом обновлении ветки.

## Что ещё не является точным паритетом с Three.js-версией

Это продвинутая миграционная сборка, но я не называю её окончательно завершённым портом до браузерного тестирования. Осталось:
- довести поведение Вендиго до точного соответствия исходному Yuka steering/FSM, включая тайминги, обход препятствий и реакции;
- перенести точные исходные анимации и все визуальные нюансы монстра/фантома;
- заменить CSS-имитацию bodycam на полноценный Babylon post-process с хроматической аберрацией и VHS-искажениями;
- проверить коллизии на всей карте, координаты всех POI, путь эвакуации и поведение машины;
- проверить все аудиофайлы в браузере, CORS и микширование; сейчас они загружаются по прямым CC0 MP3 URL;
- пройти полноценный runtime playtest и устранить обнаруженные игровые баги.

Старые Three.js-модули сохранены в `src/core`, `src/world`, `src/game`, `src/entities` как эталон поведения. Не удалять их до подтверждения функционального паритета.
