# Point of No Return: Eclipse 3D

Браузерный survival horror от первого лица. Активная ветка `feat/babylon-migration` переносит проект с Three.js на Babylon.js.

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

## Управление

| Клавиша | Действие |
|---|---|
| WASD | Движение |
| Shift | Бег с расходом выносливости |
| Мышь | Осмотр |
| E | Записка / подстанция / эвакуация |
| F | Фонарик |
| R | Фотовспышка |
| Q | ЭМП-радар |
| Esc | Пауза |

## Состояние миграции

Новая Babylon.js-точка входа уже активна. Перенесены базовый рендерер, камера, процедурная лесная сцена, часть поселения, радиовышка, подстанция, десять записок, базовые гаджеты, простая модель преследующего монстра, выносливость, сохранение прогресса и условие эвакуации.

**Это ещё не побитый по функциям перенос исходной игры.** Оригинальный сложный ИИ Yuka (патрулирование, слух, зрение с проверкой препятствий, засады), модель Вендиго, фантом, jumpscare-сценарий, полноценная система погоды/заката, исходные текстуры и процедурные звуковые эффекты пока не перенесены. Текущая модель монстра и некоторые интеракции упрощены. Старый Three.js-код сохранён в `src/core`, `src/world`, `src/game`, `src/entities` для дальнейшего переноса и сравнения.

## Структура новой реализации

```text
src/babylon/
├── assets/       GLB/glTF loader
├── audio/        централизованное управление звуком
├── engine/       Engine и Scene
├── entities/     монстр
├── game/         состояние, записки, гаджеты, сохранения
├── player/       камера и управление
├── ui/           HUD
└── world/        процедурная карта и окружение
```

Babylon.js — основной рендерер новой ветки. Three.js и Yuka пока оставлены в зависимостях только на период миграции старых модулей. После переноса и проверки их можно удалить отдельным коммитом.
