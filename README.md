# Point of No Return: Eclipse 3D

Браузерный survival horror от первого лица. Активная ветка `feat/babylon-migration` переносит игру с Three.js на Babylon.js. `main` не затронут.

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm run typecheck
npm run build
npm run dev
```

> После изменения зависимостей выполните `npm install`: lock-файл будет синхронизирован с Babylon.js.

## Что уже перенесено в Babylon.js

- Babylon Engine, Scene, камера от первого лица, pointer lock и HUD.
- Процедурная low-poly карта: лесные инстансы, дорога, поселение, домик, радиовышка, подстанция и полицейская машина.
- Десять разнесённых по миру записок с исходным лором и сохранением прогресса.
- Фонарик, фотовспышка, ЭМП-радар, здоровье и выносливость.
- ИИ Вендиго с конечным автоматом: патруль, обнаружение светом/зрением/шумом, расследование, засада, преследование, обход препятствий и оглушение вспышкой.
- Процедурная модель Вендиго с анимацией конечностей, фантом и отдельная последовательность jumpscare.
- Переход закат/ночь, спавн монстра ночью и процедурные звуковые fallback-эффекты через Web Audio.
- Условие эвакуации, пауза, победа/поражение и сохранение собранных записок.

## Что ещё требует полного паритета с оригиналом

Это рабочая миграционная ветка, но не подтверждённый финальный порт. Нужно продолжить перенос и проверку:
- исходной геометрии города/лесных POI, рельефа, коллизий деревьев и точных координат мира;
- полного рига Вендиго, оригинальных анимаций, Yuka steering и тонкой настройки поведения;
- оригинального bodycam/VHS post-processing, текстур и визуальных эффектов;
- всех оригинальных звуков, музыкальных слоёв, пространственного аудио, шагов и сирены. Сейчас есть процедурные fallback-звуки; внешние аудиофайлы в исходном архиве отсутствовали;
- настроек графики, меню и полного набора HUD-индикаторов;
- прохождения typecheck/build и runtime-тестирования в браузере.

Старые Three.js-модули сохранены в `src/core`, `src/world`, `src/game`, `src/entities` как источник поведения для проверки паритета. Не удалять их до переноса соответствующей механики.
